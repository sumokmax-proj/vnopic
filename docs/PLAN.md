# 기획서 (작성 중)

> 앱 목표: **내가 재미있게 베트남어 OPIc을 공부하고 연습할 수 있는 앱**

## 1. 사용자 & 목표
- 사용자: 본인 (1인 사용)
- 레벨: NH → **IM**
- 시험 예정일: 미정

## 2. 핵심 컨셉 — "문장이 입에 붙는 앱"

**학습 철학**
- 문법·어휘를 따로 공부해도, **문장 전체가 머리에 들어와 있지 않으면 말로 나오지 않는다.**
- 그래서 학습의 기본 단위는 단어도, 긴 답변 전체도 아닌 **"문장"** 이다.
- 최종 목표는 외운 문장을 그대로 말하는 것을 넘어, **문장을 만들 줄 알게 되는 것.**

**두 단계 목표**
1. **익숙해지기 (암기):** OPIc 빈출 답변을 구성하는 핵심 문장들을 통째로 외운다.
2. **만들어내기 (응용):** 외운 문장의 틀을 바꿔 끼워 새 문장을 만든다.

**범위 밖 (나중에)**
- 말하기·녹음·발음 평가 → 추후 확장

## 3. 학습 흐름 (초안 — 확인 필요)

### 3-1. 콘텐츠 구조
```
주제 (예: 자기소개, 거주지, 취미…)
 └─ 답변 (OPIc 질문 1개에 대한 모범 답변)
      └─ 문장 1, 문장 2, 문장 3 … ← 학습 단위
```
기존 카드(답변 1개 = 긴 문단)를 **문장 단위로 쪼개서** 하나씩 익힌 뒤, 마지막에 답변 전체로 다시 이어 붙인다.

### 3-2. 문장 하나를 익히는 단계 (점점 어렵게)
| 단계 | 활동 | 하는 일 |
|---|---|---|
| 1 | 만나기 | 한국어 뜻 + 베트남어 문장 보기 |
| 2 | 조립하기 | 섞인 단어 블록을 올바른 순서로 배열 |
| 3 | 빈칸 채우기 | 핵심 단어 1~2개를 가리고 고르기 (성조 함정 보기 포함) |
| 4 | 점점 지우기 | 가려지는 단어가 늘어남 → 거의 다 가린 상태에서 완성 |
| 5 | 떠올리기 | 한국어만 보고 베트남어 문장 전체를 떠올린 뒤 확인 |

- 각 문장은 **숙련도 0~5**를 가지며, 맞히면 다음 단계로, 틀리면 이전 단계로.
- **복습 간격 자동 조절**: 익숙한 문장은 덜 자주, 헷갈리는 문장은 더 자주 등장.

### 3-3. 문장 만들기 (응용)
- 외운 문장에서 **틀(패턴)** 을 뽑아낸다.
  - 예) `Tôi thích ___ vì ___.` (나는 ___을 좋아해요, 왜냐하면 ___)
- 바꿔 끼울 단어를 골라 **내 문장**을 만들어 보는 연습.
- 예전 버전의 "프로필 기반 AI 맞춤화"는 이 단계에 연결 (내 상황에 맞는 문장 만들기).

### 3-4. 답변 이어 말하기
- 문장들을 충분히 익히면 답변 하나를 **처음부터 끝까지 순서대로 이어 붙이기.**
