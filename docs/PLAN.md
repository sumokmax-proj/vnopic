# 기획서

> 앱 목표: **내가 재미있게 베트남어 OPIc을 공부하고 연습할 수 있는 앱**
>
> 이 문서는 개발의 기준입니다. 기획이 바뀌면 코드보다 이 문서를 먼저 고칩니다.

## 1. 사용자 & 목표
- 사용자: 본인 1명 (개발자 = 학습자)
- 레벨: NH → **IM** / 시험일: 미정
- 기기: **휴대폰 위주** (세로 화면, 한 손 터치)

## 2. 핵심 컨셉 — "문장이 입에 붙는 앱"

- 문법·어휘를 따로 공부해도 **문장 전체가 머리에 들어와 있지 않으면 말로 안 나온다.**
- 학습 단위는 단어도, 긴 답변 전체도 아닌 **"문장"**.
- 목표: 문장에 익숙해지기 → 결국 **문장을 만들 줄 알게 되기**.

## 3. 디자인 원칙 (꼭 지킬 것)

| 원칙 | 의미 |
|---|---|
| **압박 없음** | 하루 목표량, 연속 학습일, 타이머, 점수 경쟁 **없음**. 며칠 쉬어도 죄책감 주는 UI 금지 |
| **책갈피** | 앱을 열면 **어디까지 했는지 바로 보이고, 거기서 이어서** 시작. 처음부터 다시 하는 제자리걸음 느낌을 없앤다 |
| **회차(바퀴)** | 코스를 처음부터 끝까지 한 바퀴 돌면 다음 회차로 다시 시작. 반복할수록 익숙해진다 |
| **오답노트** | 반복하면서 **약한 문장이 자연스럽게 드러나고 모인다**. 앱의 정체성은 "회차를 도는 오답노트" |
| **휴대폰 우선** | 성조 타이핑 없음. 입력은 **블록 탭**으로만 |
| **단순하게** | 기능을 늘리기보다 핵심 흐름을 매끄럽게 |

## 4. 콘텐츠 구조

```
주제 (자기소개, 직장, 취미, 거주지, 여행, 음식)
 └─ 답변 (OPIc 질문 1개 + 모범 답변)
      └─ 문장 1, 문장 2, … ← 학습 단위
           └─ 블록 (의미 단위로 미리 나눈 조각)
```

- 데이터: `src/data/course.js` — 문장은 `/`로 블록을 구분해서 작성 (예: `Xin chào, / tôi / tên là / Sumok.`)
- 블록은 음절이 아니라 **의미 덩어리** (예: `công nghệ thông tin`은 한 블록)
- 초기 콘텐츠: 이전 버전(`opic-vn-im`)의 32개 답변 → 78문장으로 분리, 한국어 뜻은 문장 단위로 새로 맞춤

## 5. 학습 흐름 (MVP)

### 5-1. 코스 (메인)
```
홈 ─ [이어하기] → 문장 학습 → 문장 학습 → … → 답변 전체 보기 → 다음 질문 …
                                                       ↓ (마지막 문장까지)
                                                 회차 완주 → 다음 회차 (처음부터)
```

**질문 카드**: 베트남어 질문만 보이고, 한국어 해석은 질문을 탭해야 펼쳐짐 (베트남어 질문을 먼저 읽게 하려고). 다음 질문으로 넘어가면 다시 접힘

**문장 하나 학습**
1. **읽기** — 한국어 뜻 + 베트남어 문장 (1회차에서만 기본 표시)
2. **조립하기** — 한국어 뜻을 보고, 섞인 블록을 순서대로 탭
   - 맞는 블록 → 문장 칸으로 이동
   - 틀린 블록 → 흔들림 + 실수 1회 기록 (진행은 막지 않음)
   - **힌트** 버튼 → 다음 블록 자동 배치 (실수로 기록)
   - 2회차부터는 읽기 없이 바로 조립. **문장 보기**로 잠깐 볼 수 있음 (실수로 기록)
3. **결과** — 완성 문장 표시. 한 번도 안 틀렸으면 "완벽", 아니면 "오답노트에 추가됨"

**답변 전체 보기** — 답변의 마지막 문장을 마치면 질문 + 전체 답변을 이어서 보여줌 (이번에 틀린 문장 표시)

### 5-2. 책갈피
- 문장 하나를 끝낼 때마다 위치 자동 저장
- 홈 화면 가장 위: **"N회차 · 주제 · 질문 · 문장 k/n"** + 회차 진행 막대 + [이어하기]
- 목차에서 원하는 질문을 골라 책갈피를 옮길 수 있음

### 5-3. 회차
- 마지막 문장까지 끝내면 **회차 완주 화면**: 이번 회차에 틀린 문장 수, 지난 회차와 비교 (줄었으면 칭찬, 늘어도 비난 없음)
- [다음 회차 시작] → 책갈피가 처음으로

### 5-4. 오답노트
- 실수·힌트·문장 보기가 한 번이라도 있으면 그 문장이 오답노트에 들어감
- 오답노트에서는 **주제별로 묶어** 보여주고, 누적으로 몇 번 틀렸는지 표시 (자주 틀리는 = 약한 문장)
- [오답만 연습] → 오답노트 문장만 조립 연습 (책갈피는 움직이지 않음)
- 실수 없이 완성하면 오답노트에서 빠짐 (누적 기록은 남음)
- 홈의 목차에서 주제/질문별 오답 수를 배지로 표시 → 약한 부분이 한눈에 보임

### 5-5. 단어 뜻 보기 + 내 단어장
- **블록을 탭하면 뜻**이 아래에서 올라오는 시트로 표시
  - 블록 뜻 + 블록을 이루는 단어별 뜻 (예: `công nghệ thông tin` 정보기술 = `công nghệ` 기술 + `thông tin` 정보)
- 탭할 수 있는 곳: **읽기 단계**, **조립 완료 후** 완성 문장, **답변 전체 보기**, **오답노트**, 내 단어장
- **조립 중에는 뜻 보기 없음** — 블록 탭은 "배치"이고, 뜻을 보면 힌트가 되기 때문
- 시트에서 **☆ 저장** → 내 단어장에 추가 (블록 전체든 그 안의 단어 하나든 저장 가능). 저장한 블록은 문장에서 표시됨
- **내 단어장** (홈에서 진입): 최근 저장 순. 단어 + 뜻 + 저장한 문장(예문). [뜻 가리기]로 스스로 확인 가능. ★ 다시 탭하면 삭제
- 단어 데이터: `src/data/glossary.js` — `WORDS`(단어 사전) + `BLOCKS`(여러 단어 블록의 문맥 뜻). 블록 분해는 WORDS로 자동 계산
  - 문장을 추가하면 새 블록/단어의 뜻도 함께 추가해야 함 (테스트가 빠진 뜻을 잡아냄)

### 5-6. 한자 어휘 (별도 메뉴, 문장 코스와 연결)
**목적**: 한자를 알면 베트남어 한자어(Hán-Việt)를 빨리 익힐 수 있다. 단, 한국어와 같은 한자어라도 뜻·쓰임이 다를 수 있으니 그 차이를 분명히 보여준다.

**결정 사항 (사용자 확인)**
- 범위: **지금 코스(문장 + 질문)에 나오는 한자어만** — 모든 단어에 코스 속 예문이 있음
- 사용자 한자 실력: 한자능력검정 4급 정도 → 한자와 훈음은 그대로 보여주고, **한국 한자음 ↔ 베트남 음 ↔ 뜻** 연결에 집중
- 메뉴 성격: 가볍게 둘러보고 ⭐ 내 단어장에 담는 메뉴 + 연습문제
- 연습문제: **베트남 단어를 보고 한국어 한자어 고르기** (4지선다). 오답노트 + 진도(책갈피·회차) 추적

**용법 구분 (단어마다 표시)**
| 표시 | 의미 | 예 |
|---|---|---|
| ✅ 같음 | 한국어와 뜻이 같음 | 文化 văn hóa = 문화 |
| 🟡 쓰임 차이 | 뜻은 통하지만 쓰임이 다름 | 家庭 gia đình = 가정 → 베트남어는 '가족' |
| ⚠️ 뜻 다름 | 같은 한자어인데 뜻이 다름 | 趣味 thú vị = 취미 → 베트남어는 '흥미로운' |
| 🔄 순서 반대 | 한국어는 한자 순서가 반대 | 單簡 đơn giản → 한국어 簡單 간단 |
| 🇻🇳 베트남식 | 한국어에 없는 한자 조합 (연습문제 제외) | 預案 dự án → 프로젝트 |
| 🔀 일부 고유어 | 한자 + 베트남 고유어 (연습문제 제외) | 分 + mềm → phần mềm 소프트웨어 |

**화면**
- 홈 → **한자 어휘** 메뉴
  - 연습문제 책갈피 카드 (N회차 · k/전체, 이어서 풀기) + 한자 오답 카드 (틀린 단어만 풀기)
  - 받침·초성 대응 규칙 (접어 두는 안내)
  - 단어 목록 + 필터 (전체 / 뜻 다름 / 쓰임 차이 / 순서 반대 / 같음 / 베트남식 / 오답)
- **한자 시트** (단어 탭): 한자 + 한국 음, 글자별 훈음, 같은 한자가 들어간 다른 단어, 같은 소리 다른 한자, 용법 구분 + 설명, 뜻, 코스 속 예문, ☆ 저장
- **연습문제**: 베트남 단어 → 한국어 한자어 4개 중 선택 → 바로 정답 표시 + 한자·훈음·용법 차이·예문 공개 → 다음
  - 오답 보기는 같은 음절을 공유하는 단어를 우선 (예: thành công → 성공 / 성원 / 완성 …) → 소리 대응을 써야 풀 수 있음
  - 순서: 코스에서 처음 나오는 순서
  - 틀리면 한자 오답노트에, 다음에 한 번에 맞히면 빠짐 (문장 오답노트와 같은 규칙)
- 문장 코스와 연결: 단어 뜻 시트에 한자 정보 표시 → 탭하면 한자 시트. 내 단어장에도 한자 표시

**데이터**: `src/data/hanviet.js` — 단어(한자·한국 음·구분·설명), 글자별 훈(訓), 대응 규칙
- 한자 어원은 Claude가 작성. 어원이 불확실한 단어는 넣지 않음

## 6. 데이터 저장
- 서버 없음. 진도는 브라우저 `localStorage` (`vnopic:progress`)
- 저장 항목: 회차, 책갈피 위치, 회차별 틀린 문장, 오답노트, 문장별 누적 기록, 마지막 백업 시각, 내 단어장
- 저장 형식 버전: 3 (v1 → v2: 내 단어장 `words` 추가 / v2 → v3: 한자 연습 진도 `hanja` 추가. 예전 진도·백업 파일은 자동 변환)
- 위험: 브라우저 데이터 삭제 시 진도 사라짐 → **백업**으로 대비
  - 홈 맨 아래 "진도 백업": [백업 파일 저장] → `vnopic-backup-날짜.json` 다운로드 / [백업 불러오기] → 파일 선택 후 확인하면 진도 교체
  - 백업을 재촉하는 알림은 두지 않음 (압박 없음 원칙). 마지막 백업 날짜만 조용히 표시
